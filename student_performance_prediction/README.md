
# Student Performance Prediction System

## Project Overview
A machine learning project that predicts student final grades
using academic and study-related information.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Streamlit

## Features
- Student dataset analysis
- Exploratory data visualization
- Linear Regression and Random Forest comparison
- Final grade prediction
- Interactive web dashboard

## Dataset
UCI Student Performance dataset:
https://archive.ics.uci.edu/dataset/320/student+performance

Download the dataset and place student-mat.csv in the project folder.

## How to Run

Install the libraries:

    python -m pip install -r requirements.txt

Train the model:

    python train_model.py

Start the application:

    python -m streamlit run app.py

## Evaluation
The model reports MAE, RMSE, and R-squared.
Run the training script to obtain actual results.
